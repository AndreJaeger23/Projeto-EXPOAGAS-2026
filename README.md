# Projeto-EXPOAGAS-2026
Projeto web para a EXPOAGAS 2026 (com UniRitter) que usa IA para evitar desperdício no varejo. Ele monitora o vencimento de produtos e sugere descontos ou combos. O site exibe a economia gerada (em R$ e kg) e ganhos ESG, com potencial futuro de integração a sistemas de gestão e e-commerce
